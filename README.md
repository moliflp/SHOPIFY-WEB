# Tema Tecunelo (Shopify)

Tema de una sola página: home con 3D, catálogo, ficha de producto, carrito y textos legales.

## Productos
Se leen de Shopify (colección "Todos los productos"). Para que aparezcan:
- **Título** = el nombre exacto de tu archivo original (así enlaza con su ficha).
- **Tipo de producto** = Audio, Carga, Hogar, Gaming o Coche.
- **Precio de comparación** solo si hay rebaja real.
- La primera imagen del producto se usa como foto.

## Pago
"Finalizar compra" mete el carrito en Shopify y abre /checkout. Los códigos de descuento se aplican allí.

## Flujo
Edita aquí -> commit -> push a main -> Shopify actualiza el tema conectado.
